# RoleFit AI 0.12.0: unsigned preview beta.1

<!-- Curated preview-note source. Publication occurs only after every native build, packaged smoke, installer lifecycle, checksum, and atomic-publication gate succeeds. -->

This unsigned public preview improves how RoleFit reads job postings. It
includes browser extension **1.4.0** and desktop bridge API **13**. The bridge
API is unchanged. RoleFit stays local-first and browser-primary: there is no
app account, hosted workspace, cloud synchronization, or telemetry service.

Version 0.12.0 imports full Microsoft Careers postings. A closed Rippling
posting now asks you to paste the job instead of importing the company's
careers page. The browser extension can now read a posting that a company
careers page embeds from a recognized job board. It remains a preview rather
than a stable release because public installers are still unsigned, automatic
updates are not implemented, and portable formats may still change without
migrations.

## Upgrading from an earlier preview

- **From 0.11.x:** 0.12.0 reads and writes the same workspace, tracker,
  settings, and backups as 0.11.0 and 0.11.1, so no backup step is needed to
  move between them.
- **From 0.10.0 or earlier:** the RoleFit 0.11.0 preview's upgrade notes also
  apply. After any launch of 0.11.0 or later, 0.10.0 and earlier refuse to
  save settings and refuse its backups. If you may need to roll back, create a
  `.rolefit-backup` in your current version before upgrading.
- After opening this preview, reload the unpacked extension once from the
  browser's Extensions page so it picks up extension 1.4.0. Firefox removes
  temporary add-ons when it quits, so load it again after a restart.
- Reload any RoleFit tab left open from the previous version.
- Quit the existing RoleFit application before installing this preview.
- On macOS, replace the existing `RoleFit AI.app` in Applications.
- On Windows, run the new installer over the existing installation. The
  installer retains RoleFit's internal upgrade and local-data identity.
- The installed companion continues to use the existing RoleFit workspace and
  provider configuration.
- Save important standalone cover letters as `.cover` files separately. The
  current `.rolefit-backup` allowlist does not include saved cover-letter
  variants.

## Before installing

- macOS Gatekeeper will identify the app as coming from an unidentified
  developer. The app has an ad-hoc integrity signature but is not notarized or
  signed with Apple Developer ID.
- Windows SmartScreen will warn that the publisher is unknown. The installer
  is not Authenticode-signed.
- Download only from the canonical RoleFit GitHub Release and compare the file
  against `SHA256SUMS.txt` before opening it.

## Added

- **Full Microsoft Careers postings.** Pasting an
  `apply.careers.microsoft.com` job link now imports the whole posting,
  including its Responsibilities and Qualifications, from Microsoft's public
  position details. Before, it imported only a summary of about a third of
  the posting. A link to a posting that no longer exists asks you to paste the
  job instead.
- **Rippling postings import exactly, or not at all.** Rippling job links
  (`ats.rippling.com/<company>/jobs/<id>`) now read Rippling's public job
  board. A closed or unknown posting asks you to paste the job. Before,
  Rippling redirected such links to the company's careers page, and RoleFit
  imported that page as the job.
- **The extension reads embedded job postings.** When a company careers page
  shows its posting inside a frame from the page's own origin (the same scheme,
  host, and port), and RoleFit does not recognize the page's own description
  area, the extension now captures that frame's text. When the frame comes from
  a recognized public job board (for example Greenhouse, Ashby, Workday,
  Workable, or Rippling, as well as Lever and Jobvite posting pages), RoleFit
  imports that board's full posting. This happens only when the page itself is
  not a recognized posting and its frames name exactly one posting. The
  extension asks for no new browser permission, and it never reads the content
  of another origin's frame.

## Known issues

- PDF import was tested on synthetic resumes; accuracy on real-world layouts
  and live provider interpretation have not been measured. Two layouts read
  imperfectly, with no text lost:
  - A dated sidebar whose headings look like its entries, beside a column
    without bullets, reads as one column.
  - Some values at a tab stop stay joined to the title with a Check.
- Backing up or restoring a workspace near the maximum through the desktop
  companion has not been verified yet. Large backups use substantial memory
  while they are built.
- Outside Rippling, a posting link that redirects to a general careers page
  imports that page's text as the job; check the brief.
- A posting inside a frame from another origin is still missed when that frame
  is not a recognized job-board posting, or when the frames name more than one
  posting.
- Lever and Jobvite frames were tested only with offline fixtures, not against
  live postings.
- Extension 1.4.0's frame capture was verified by automated tests and a
  Chromium page check. It has not been hand-tested in an installed Chrome or
  Firefox extension.

## Included

- Native macOS downloads for Apple silicon and Intel, plus a native Windows x64
  installer and a checksum file covering every published artifact.

RoleFit's browser app, loopback server, paired extension, and workspace remain
on the user's device. AI input goes directly to the provider selected for that
stage only when the user runs the workflow; provider credentials and personal
workspace data are not part of the public release artifacts.
