# RoleFit AI 0.11.1: unsigned preview beta.1

<!-- Curated preview-note source. Publication occurs only after every native build, packaged smoke, installer lifecycle, checksum, and atomic-publication gate succeeds. -->

This unsigned public preview is a fix release for RoleFit 0.11.0. It includes
browser extension **1.3.0** and desktop bridge API **13**, both unchanged, and
keeps the product local-first and browser-primary: there is no app account,
hosted workspace, cloud synchronization, or telemetry service.

Version 0.11.1 fixes three issues in Prepare, Polish, and Answers and adds no
new features. It remains a preview rather than a stable release because public
installers are still unsigned, automatic updates are not implemented, and
portable formats may still change without migrations.

## Upgrading from an earlier preview

- **From 0.11.0:** 0.11.1 reads and writes the same workspace, tracker,
  settings, and backups as 0.11.0, so no backup step is needed to move between
  them.
- **From 0.10.0 or earlier:** the RoleFit 0.11.0 preview's upgrade notes also
  apply. After any launch of 0.11.x, 0.10.0 and earlier refuse to save
  settings and refuse its backups, so create a `.rolefit-backup` in your
  current version before upgrading if you may need to roll back.
- Reload any RoleFit tab left open from the previous version before editing.
  A tab still running 0.11.0 may refuse to save a new answer containing a
  word such as "Node.js" until it is reloaded.
- Quit the existing RoleFit application before installing this preview.
- On macOS, replace the existing `RoleFit AI.app` in Applications.
- On Windows, run the new installer over the existing installation. The
  installer retains RoleFit's internal upgrade and local-data identity.
- The installed companion continues to use the existing RoleFit workspace and
  provider configuration.
- The browser extension is unchanged (1.3.0); no reload is needed.
- Save important standalone cover letters as `.cover` files separately. The
  current `.rolefit-backup` allowlist does not include saved cover-letter
  variants.

## Before installing

- macOS Gatekeeper will identify the app as coming from an unidentified
  developer. The app has an ad-hoc integrity signature but is not notarized or
  signed with Apple Developer ID.
- Windows SmartScreen will warn that the publisher is unknown. The installer
  is not Authenticode-signed.
- Download only from the canonical RoleFit GitHub Release and compare the file
  against `SHA256SUMS.txt` before opening it.

## Fixed

- **The Starter template never counts as your resume.** Once you saved a Draft
  or application in the current preparation, or opened a saved one, opening
  the bundled Starter template used to count as your resume for Answers,
  Polish, and Apply readiness. It is now always treated as a sample: Prepare
  shows "Starter template", and Answers asks you to add your resume first.
  Open or save your own resume to continue. (Known issue since 0.9.1.)
- **Polish names the provider it is waiting for.** When the provider chosen
  for Resume Polish or Cover letter Polish is missing or not ready, the
  Resume and Cover letter rails now say what to do, for example "Add Codex ·
  CLI in RoleFit Companion.", instead of "Check AI settings". Choosing Claude
  Code CLI for Resume Polish in Settings › Models now starts at Opus 5.5 High,
  the Claude setting it was benchmarked with, rather than Sonnet 5.5 Low. Your
  saved choices are unchanged.
- **Answers counts "Node.js" as one word.** Word counts and word limits in
  Answers now treat a word with inner periods, such as "Node.js", "U.S.", or
  "example.com", as one word, as most application forms do.

## Known issues

- PDF import was tested on synthetic resumes; accuracy on real-world layouts
  and live provider interpretation have not been measured. Two layouts read
  imperfectly, with no text lost: a dated sidebar whose headings look like its
  entries, beside a column without bullets, reads as one column; and some
  values at a tab stop stay joined to the title with a Check.
- Backing up or restoring a workspace near the maximum through the desktop
  companion has not been verified yet. Large backups use substantial memory
  while they are built.
- Pasting a Microsoft Careers link imports only a summary of the posting;
  capture the page with the extension instead.
- A posting link that redirects to a general careers page imports that page's
  text as the job; check the brief.
- The extension reads only the page's top frame, so a description inside an
  embedded frame on a company careers site is missed.

## Included

- Native macOS downloads for Apple silicon and Intel, plus a native Windows x64
  installer and a checksum file covering every published artifact.

RoleFit's browser app, loopback server, paired extension, and workspace remain
on the user's device. AI input goes directly to the provider selected for that
stage only when the user runs the workflow; provider credentials and personal
workspace data are not part of the public release artifacts.
