# RoleFit AI 0.8.0: unsigned preview beta.1

<!-- Curated preview-note source. Publication occurs only after every native build, packaged smoke, installer lifecycle, checksum, and atomic-publication gate succeeds. -->

This unsigned public preview packages the RoleFit 0.8.0 desktop/browser
milestone. It includes browser extension **1.2.1** and desktop bridge API **13**
while keeping the product local-first and browser-primary: there is no app
account, hosted workspace, cloud synchronization, or telemetry service.

Version 0.8.0 replaces About you with one candidate Profile, lets Resume Polish
draw on that Profile, adds an optional final application review, and keeps
content checks advisory. It remains a preview rather than a stable release
because public installers are still unsigned, automatic updates are not
implemented, and portable formats may still change without migrations.

## Upgrading from an earlier preview

- **Before upgrading, create a `.rolefit-backup` in 0.7.0** if you may need to
  roll back. Resumes and backups saved by 0.8.0 do not open in 0.7.0.
- **`.resume` files saved by 0.7.0 will not open in 0.8.0.** Documents now
  require a `bulletIndentPt` style value (the new Bullet indent setting) and
  older files are rejected instead of guessed. This covers resumes in your
  workspace, resumes saved with tracked applications, and resumes inside a
  0.7.0 `.rolefit-backup`, so a workspace holding older resumes cannot be backed
  up or restored until they are updated. To keep an older file, add
  `"bulletIndentPt": 14.73` to its `style` object. That value reproduces the
  previous layout at the default 10pt body size; at another body size, use
  14.73 × `baseFontSizePt` / 10. The companion's **Workspace** section opens the
  workspace folder. `.cover` files are unaffected.
- **Open accepts only `.resume` and `.cover` files.** Text, Markdown, and CSV
  resumes and text or Markdown cover letters no longer import, and a base resume
  still stored as `.txt`, `.md`, or `.csv` no longer appears as a document or
  history choice. Paste its content into a blank document and save it as
  `.resume`; the old files stay in the workspace.
- **Guidance > Honest context is now Profile > Background**, and experience
  evidence rows from About you are appended to it once under
  `## Experience by type`, with every declared value kept. Stages that use the
  Background decline to run while it is over 12,000 characters, where earlier
  versions clipped it, so shorten a longer Background after upgrading.
- Settings saved by 0.7.0 convert to the new names automatically. Reload any
  RoleFit tab left open from the previous version before editing Settings.
- New Claude and Codex stages default to Sonnet 5.5 and GPT-6.1 Sol. Update
  Claude Code to 2.1.284 or later and Codex CLI to 0.159 or later before using
  them.
- Quit the existing RoleFit application before installing this preview.
- On macOS, replace the existing `RoleFit AI.app` in Applications.
- On Windows, run the new installer over the existing installation. The
  installer retains RoleFit's internal upgrade and local-data identity.
- The installed companion continues to use the existing RoleFit workspace and
  provider configuration.
- After opening this preview, reload the unpacked extension once from the
  browser's Extensions page so it picks up extension 1.2.1. Firefox removes
  temporary add-ons when it quits, so load it again after a restart.
- Save important standalone cover letters as `.cover` files separately. The
  current `.rolefit-backup` allowlist does not include saved cover-letter
  variants.

## Before installing

- macOS Gatekeeper will identify the app as coming from an unidentified
  developer. The app has an ad-hoc integrity signature but is not notarized or
  signed with Apple Developer ID.
- Windows SmartScreen will warn that the publisher is unknown. The installer
  is not Authenticode-signed.
- Download only from the canonical RoleFit GitHub Release and compare the file
  against `SHA256SUMS.txt` before opening it.

## Included

- **Settings > About you is now Profile**: your declared facts plus one
  **Background** field for experience beyond, or in more depth than, the
  resume. Every stage that uses candidate context receives the whole
  Background or, above 12,000 characters, declines with a message naming the
  limit.
- **Resume Polish can draw on the Profile.** A Background heading that names a
  resume entry links its text to that entry, so Polish can rewrite the entry's
  bullets from it and propose up to two new bullets per entry. Profile-based rows are
  labelled **Profile**, and Undo removes exactly the bullet that was added.
- **Resume Polish can remove and reorder bullets** within an entry. The review
  groups changes as Rewrite, Add, Remove, and Reorder, with Accept and Discard
  per group when several show, and Undo restores a removed bullet or the
  original order.
- **Final application review** optionally checks the materials you are
  including together before you apply. It is session-only and never
  blocks Apply.
- **Content checks stay advisory.** Usable resume, cover letter, answer, and
  Fit output stays reviewable with evidence and quality warnings; security and
  document-integrity protections still block. Fit warnings now appear beside
  the match, gap, or eligibility finding they concern, and gap notes are no
  longer flagged for ordinary wording such as "does not mention". Polish's
  "Proposed improvements" summary is no longer flagged as unsupported.
- **Job analysis is plain structured extraction.** It may summarize the posting
  concisely and no longer shows extraction warnings in Prepare or saved jobs.
- Required job terms are kept in polished bullets, and accepting an edit that
  removes supported terminology warns you. A default-on **Bold keywords** switch
  controls bold terms in polished bullets.
- Cover letters cite the paragraph evidence behind each claim, and Fit can
  report that a posting gives too little information to judge.
- **Applications** has a redesigned detail view and inspector, grouped
  reversible stages, posting IDs in the table and search, and loading
  skeletons for Applications and Analytics. Recovery drafts now appear only
  after an interrupted session.
- **The editor** gains a Bullet indent setting, add/remove for entry title and
  subtitle rows, long-field wrapping, and kerned PDF output that matches the
  on-screen widths. Resume Open accepts only `.resume` files and Cover Letter
  Open only `.cover` files.
- **Provider catalog:** GPT-6.1 Sol and Claude Sonnet 5.5 are the defaults for
  new Codex and Claude stages; saved selections stay selected, and retired
  Codex choices move to GPT-6.1 Sol. GPT-6.1 Sol may need Codex CLI 0.159 or
  later, and Sonnet 5.5 needs Claude Code 2.1.284 or later.
- **Workspace preferences** no longer lose newer settings to a stale tab or
  window; a conflicting save keeps your own changes and adopts the rest.
- **The desktop companion's Browser extension section** has an Access card for
  pending and paired browsers (**Approve & restart**, two-step **Remove**), a
  per-browser install guide, and copy fields for the folder path, setup
  addresses, and port.
- Browser extension 1.2.1 removes a retired tracker status label from the popup.
- Native macOS downloads for Apple silicon and Intel, plus a native Windows x64
  installer and a checksum file covering every published artifact.

RoleFit's browser app, loopback server, paired extension, and workspace remain
on the user's device. AI input goes directly to the provider selected for that
stage only when the user runs the workflow; provider credentials and personal
workspace data are not part of the public release artifacts.
