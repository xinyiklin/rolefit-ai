# RoleFit AI 0.10.0: unsigned preview beta.1

<!-- Curated preview-note source. Publication occurs only after every native build, packaged smoke, installer lifecycle, checksum, and atomic-publication gate succeeds. -->

This unsigned public preview adds Handshake job import to the browser
extension. It includes browser extension **1.3.0** and desktop bridge API
**13**, and keeps the product local-first and browser-primary: there is no app
account, hosted workspace, cloud synchronization, or telemetry service.

It remains a preview rather than a stable release because public installers
are still unsigned, automatic updates are not implemented, and portable formats
may still change without migrations.

## Upgrading from an earlier preview

- **From 0.9.x:** 0.10.0 reads and writes the same workspace, tracker,
  settings, and backups as 0.9.0 and 0.9.1, so no backup step is needed to
  move between them.
- **From 0.8.0 or earlier:** the RoleFit 0.9.0 preview's upgrade notes also
  apply. Trackers, settings, and backups saved by 0.9.0 or later do not open in
  0.8.0, so create a `.rolefit-backup` in 0.8.0 before upgrading if you may
  need to roll back.
- Reload any RoleFit tab left open from the previous version before editing.
- Quit the existing RoleFit application before installing this preview.
- On macOS, replace the existing `RoleFit AI.app` in Applications.
- On Windows, run the new installer over the existing installation. The
  installer retains RoleFit's internal upgrade and local-data identity.
- The installed companion continues to use the existing RoleFit workspace and
  provider configuration.
- After opening this preview, reload the unpacked extension once from the
  browser's Extensions page so it picks up extension 1.3.0. Firefox removes
  temporary add-ons when it quits, so load it again after a restart.
- Save important standalone cover letters as `.cover` files separately. The
  current `.rolefit-backup` allowlist does not include saved cover-letter
  variants.

## Before installing

- macOS Gatekeeper will identify the app as coming from an unidentified
  developer. The app has an ad-hoc integrity signature but is not notarized or
  signed with Apple Developer ID.
- Windows SmartScreen will warn that the publisher is unknown. The installer
  is not Authenticode-signed.
- Download only from the canonical RoleFit GitHub Release and compare the file
  against `SHA256SUMS.txt` before opening it.

## New

- **Import Handshake postings with the extension.** On a signed-in Handshake
  job page or the job selected in Handshake's search view, the extension now
  opens the shortened description and sends only that posting: not Similar
  Jobs from other employers and not other students' alumni profiles. If
  RoleFit does not recognize the page's layout (for example, while the job is
  still loading), it captures the whole page as it does on other sites,
  including Similar Jobs and alumni names, so check the brief. When it
  recognizes the page, it sends the posting's own `/jobs/<id>` link, so a
  posting captured with 0.10.0 or later is recognized on the same Handshake
  address whether you opened it directly or from a search, and the popup shows
  its role and employer. Before, the extension sent only the first lines of the
  description along with the rest of the page. Pasting a Handshake link on
  Prepare still does not work, because Handshake requires your sign-in.
- **Supported job sites are documented.** The RoleFit README now lists what
  pasting a link and capturing a page each get on Greenhouse, Lever, Ashby,
  Workday, LinkedIn, Indeed, Handshake, and other job sites, which sites refuse
  link import, and known limits.

## Fixed

- **A job page's title can no longer stall RoleFit.** Opening the extension
  popup on a page with a crafted title or long blank page text could stop the
  local RoleFit server from answering for seconds to tens of seconds while it
  read the role and employer. Those reads now finish in milliseconds and return
  the same role and employer for LinkedIn, Indeed, and other page titles.
- **Closing a tab after Save as skipped no longer asks you to confirm.** The
  same holds with a Skipped record open. The warning appeared even when
  nothing was left to save. A document you edited still warns until its
  recovery copy is stored, about a second, and unsaved Answers or running AI
  work still warn.
- **Update application offers only the PDFs that changed.** Its download
  prompt no longer offers a resume or cover letter that matches the copy
  already saved on that application, and it updates without a prompt when
  neither changed. Its button names the PDF it downloads.

## Known issues

- Once you save a Draft or application in the current preparation, or open a
  saved one, opening the bundled Starter template still counts as your resume
  for Answers, Polish, and Apply readiness. Open your own resume before using
  them. (Carried over from 0.9.1.)
- Pasting a Microsoft Careers link imports only a summary of the posting;
  capture the page with the extension instead.
- A posting link that redirects to a general careers page imports that page's
  text as the job; check the brief.
- The extension reads only the page's top frame, so a description inside an
  embedded frame on a company careers site is missed.

## Included

- Native macOS downloads for Apple silicon and Intel, plus a native Windows x64
  installer and a checksum file covering every published artifact.

RoleFit's browser app, loopback server, paired extension, and workspace remain
on the user's device. AI input goes directly to the provider selected for that
stage only when the user runs the workflow; provider credentials and personal
workspace data are not part of the public release artifacts.
