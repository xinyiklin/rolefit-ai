# RoleFit AI 0.11.0: unsigned preview beta.1

<!-- Curated preview-note source. Publication occurs only after every native build, packaged smoke, installer lifecycle, checksum, and atomic-publication gate succeeds. -->

This unsigned public preview imports a text-based PDF resume for review, raises
the tracker limit to 2,000 applications, and updates the desktop companion to
Electron 43.7.9 for security fixes. It includes browser extension **1.3.0**
and desktop bridge API **13**, and keeps the product local-first and
browser-primary: there is no app account, hosted workspace, cloud
synchronization, or telemetry service.

It remains a preview rather than a stable release because public installers
are still unsigned, automatic updates are not implemented, and portable formats
may still change without migrations.

## Upgrading from an earlier preview

- **From 0.10.0 or 0.9.x:** 0.11.0 opens your existing workspace, tracker,
  settings, and backups. Rolling back is limited, so create a
  `.rolefit-backup` in your current version before upgrading if you may need
  to return to it:
  - After any launch of 0.11.0, settings include the new Resume import model
    choice. 0.10.0 and earlier then refuse to save settings, leave preferences
    out of their own backups, and refuse backups made by 0.11.0.
  - Once your tracker holds more than 500 applications, 0.10.0 and earlier
    refuse to open it, and they also refuse backups larger than their old
    limits.
  - Older builds fail closed in each case and change nothing.
- **From 0.8.0 or earlier:** the RoleFit 0.9.0 preview's upgrade notes also
  apply. Trackers, settings, and backups saved by 0.9.0 or later do not open in
  0.8.0, so create a `.rolefit-backup` in 0.8.0 before upgrading if you may
  need to roll back.
- Reload any RoleFit tab left open from the previous version before editing.
- Quit the existing RoleFit application before installing this preview.
- On macOS, replace the existing `RoleFit AI.app` in Applications.
- On Windows, run the new installer over the existing installation. The
  installer retains RoleFit's internal upgrade and local-data identity.
- The installed companion continues to use the existing RoleFit workspace and
  provider configuration, including saved API keys. If a provider ever asks you
  to reconnect after upgrading, enter its key again.
- The browser extension is unchanged at 1.3.0.
- Save important standalone cover letters as `.cover` files separately. The
  current `.rolefit-backup` allowlist does not include saved cover-letter
  variants.

## Before installing

- macOS Gatekeeper will identify the app as coming from an unidentified
  developer. The app has an ad-hoc integrity signature but is not notarized or
  signed with Apple Developer ID.
- Windows SmartScreen will warn that the publisher is unknown. The installer
  is not Authenticode-signed.
- Download only from the canonical RoleFit GitHub Release and compare the file
  against `SHA256SUMS.txt` before opening it.

## New

- **Import a PDF resume.** Resume › Open › **Import PDF** reads a text-based
  PDF on this computer into an editable, unsaved resume with a review rail:
  - The rail shows the original PDF, **Check** items for uncertain structure,
    and a **Not placed** list. Every character of the PDF's text is placed,
    listed, or used as structure; words are never reworded, and an import
    that cannot account for its text is refused.
  - **Save variant** saves an ordinary `.resume`; **Discard import** restores
    exactly what the editor held before.
  - Resume Polish and Cover letter Polish wait until the review is saved or
    discarded.
  - Scanned or image-only, password-protected, damaged, over-10-page or
    over-10 MB PDFs, and PDFs with filled form fields or added text boxes are
    refused with a reason.
  - Optional: **Interpret with ‹provider›** (Settings › Models › Resume
    import) sends the extracted text to the provider you choose, only when
    you click it. The reply can only arrange the PDF's own text. A reply that
    brings in other text, reuses text, or drops or reorders words inside a
    field is not used, and the local reading stays; pieces it leaves out are
    listed under **Not placed**.
- **The tracker holds up to 2,000 applications.** The limit was 500.
- **Large trackers stay quick:**
  - Duplicate checks compare only records that could plausibly match, and
    after an edit they recheck only that record.
  - A save sends and receives only the applications that changed, unless
    another tab or an outside edit changed the tracker first.
- **Backups fit a 2,000-application workspace.** A `.rolefit-backup` now
  allows up to 5,000 files, 48 MB per file, and 256 MB in total. The backup
  format is unchanged.

## Security

- **The desktop companion runs Electron 43.7.9** (Chromium 150, Node 24.21).
  This fixes four high-severity advisories in the Electron 43.2.0 that 0.10.0
  shipped:
  - GHSA-gr2m-v5gq-v685: sandbox inheritance for opened windows
  - GHSA-j84w-jfhq-vhvj: cross-origin reads through file and HTTP protocol
    handlers
  - GHSA-9qh4-3jw8-366w: `<webview>` Node.js integration in Web Workers
  - GHSA-qmv3-fv6v-rmhq: sandboxed preload code-cache poisoning

  It also picks up Electron's later Chromium and V8 security fixes.

## Known issues

- PDF import was tested on synthetic resumes; accuracy on real-world layouts
  and live provider interpretation have not been measured. Two layouts read
  imperfectly, with no text lost: a dated sidebar whose headings look like its
  entries, beside a column without bullets, reads as one column; and some
  values at a tab stop stay joined to the title with a Check.
- Backing up or restoring a workspace near the new maximum through the desktop
  companion has not been verified yet. Large backups use substantial memory
  while they are built.
- Once you save a Draft or application in the current preparation, or open a
  saved one, opening the bundled Starter template still counts as your resume
  for Answers, Polish, and Apply readiness. Open your own resume before using
  them. (Carried over from 0.9.1.)
- Pasting a Microsoft Careers link imports only a summary of the posting;
  capture the page with the extension instead.
- A posting link that redirects to a general careers page imports that page's
  text as the job; check the brief.
- The extension reads only the page's top frame, so a description inside an
  embedded frame on a company careers site is missed.

## Included

- Native macOS downloads for Apple silicon and Intel, plus a native Windows x64
  installer and a checksum file covering every published artifact.

RoleFit's browser app, loopback server, paired extension, and workspace remain
on the user's device. AI input goes directly to the provider selected for that
stage only when the user runs the workflow; provider credentials and personal
workspace data are not part of the public release artifacts.
