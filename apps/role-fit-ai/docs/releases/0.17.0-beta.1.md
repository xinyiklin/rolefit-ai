# RoleFit AI 0.17.0: unsigned preview beta.1

<!-- Curated preview-note source. Publication occurs only after every native build, packaged smoke, installer lifecycle, checksum, and atomic-publication gate succeeds. -->

This unsigned public preview runs Claude and OpenAI the same way over their
CLIs and APIs, adds one-click provider plans, gives every text role its own
size, and lets cover letters share the resume's styles and spacing. It
includes browser extension **1.4.0** and desktop bridge API **13**, both
unchanged. RoleFit stays local-first and browser-primary: there is no app
account, hosted workspace, cloud synchronization, or telemetry service.

It remains a preview rather than a stable release because public installers
are still unsigned, automatic updates are not implemented, and portable
formats may still change without migrations.

## Upgrading from an earlier preview

- **Create a `.rolefit-backup` first if you may return to 0.16.0 or earlier.**
  0.17.0 reads every earlier `.resume`, `.cover`, settings file, and backup,
  but resumes and letters it saves use the new per-field sizes, and 0.16.0
  refuses to open them or a backup that contains them.
- **Settings from any earlier version** are repaired when 0.17.0 loads them:
  - A stage set to a removed model moves to that model's successor: Claude
    Fable 5 to Fable 5.1, Opus 5 and 4.x to Opus 5.5, Sonnet 5 and 4.6 to
    Sonnet 5.5, Haiku 4.5 to Haiku 5.5, GPT-6 Sol and GPT-5.6 Sol or Terra to
    GPT-6.1 Sol, and GPT-5.6 Luna to GPT-6 Luna. Its effort is kept when the
    new model supports it.
  - A Claude API or OpenAI API stage saved without an effort runs at Low
    (Claude) or Medium (OpenAI).
- **Documents from any earlier version** open unchanged. Their old base size
  becomes per-field sizes when you next save. A resume whose base size was not
  10 pt may shift bullet text and the section rule slightly, by under a point
  at 10.5 pt.
- **Rolling back to 0.16.0** after using 0.17.0: restore the backup you made
  before upgrading. Also set any stage using Haiku 5.5 to another model first;
  0.16.0 does not know Haiku 5.5.
- The earlier previews' upgrade notes still apply when you skip versions: see
  0.16.0 for Antigravity and GPT-5.5, 0.14.0 for the added font families, and
  0.11.0 for upgrades from 0.10.0 or earlier.
- The extension is unchanged from 0.12.0. If you are upgrading from 0.11.x or
  earlier, reload the unpacked extension once so it picks up extension 1.4.0.
  Firefox removes temporary add-ons when it quits, so load it again after a
  restart.
- Reload any RoleFit tab left open from the previous version.
- Quit the existing RoleFit application before installing this preview.
- On macOS, replace the existing `RoleFit AI.app` in Applications.
- On Windows, run the new installer over the existing installation. The
  installer retains RoleFit's internal upgrade and local-data identity.
- The installed companion continues to use the existing RoleFit workspace and
  provider configuration.
- Save important standalone cover letters as `.cover` files separately. The
  current `.rolefit-backup` allowlist does not include saved cover-letter
  variants.

## Before installing

- macOS Gatekeeper will identify the app as coming from an unidentified
  developer. The app has an ad-hoc integrity signature but is not notarized or
  signed with Apple Developer ID.
- Windows SmartScreen will warn that the publisher is unknown. The installer
  is not Authenticode-signed.
- Download only from the canonical RoleFit GitHub Release and compare the file
  against `SHA256SUMS.txt` before opening it.

## New

- **Provider plans.** Settings › Models has a **Plan** control: **Hybrid
  (recommended)**, **Claude only**, or **OpenAI only** sets every stage's
  provider, model, and effort in one step. Rows stay editable; the Plan then
  reads *Custom*.
- **One switch per vendor between CLI and API.** **Claude** and **OpenAI**
  each move all of that vendor's stages between the CLI and the API, keeping
  each stage's model and effort. A choice is available once that provider is
  added in the companion.
- **Per-field text sizes.** Each text role has its own default size (name,
  section heading, titles, subtitles, contact, skill labels, body), shared by
  resumes and letters. The Styles menu adds Name and Body rows, and sizing a
  word no longer re-spaces its line.
- **The cover letter has a Spacing menu**, with line spacing and the header
  gaps. Style menus are more compact in both editors.

## Changed

- **CLI and API behave the same.** Claude API and OpenAI API requests now use
  the stage's effort, Low through Max, like the CLIs; neither has an off
  setting. Codex's Ultra stays CLI-only. Higher effort uses more API tokens.
- **Provider names** read Claude · CLI, Claude · API, OpenAI · CLI, and
  OpenAI · API in RoleFit and the companion.
- **Current models only.** Claude Fable 5.1, Opus 5.5, Sonnet 5.5, and Haiku
  5.5 (new), and OpenAI GPT-6 Astra, GPT-6.1 Sol, and GPT-6 Luna, the same on
  CLI and API. The OpenAI API default is GPT-6.1 Sol.
- **Document titles follow their own name** until you rename them: each
  document is titled from its own header name and the prepared company, and
  typing a name retitles it. A new session opens both Starters.
- **A new letter starts in the resume's default style**, and letters use the
  resume's style names and page settings.
- **Alignment never changes line breaks.** Justified text only stretches the
  spaces of lines a ragged paragraph would choose; justified text from an
  earlier version may re-break once.

## Fixed

- **Toolbar size and font steps** move each run from its own size, and a
  skills row's `: ` is one joined piece, so stepping a whole row or document
  no longer drifts.
- **An Application answer made with a now-removed model** still names its
  model.

## Known issues

- The OpenAI API's new effort setting has not been run live. OpenAI documents
  Low through Max for GPT-6.1 Sol; Astra's and Luna's API levels follow the
  Codex catalog. The Claude API was checked live on every listed model at Low
  and Max.
- The Plan and CLI/API controls were checked in Chromium but not in Firefox.
- Some single-vendor plan settings are untested best guesses: Final
  application review on either plan, and OpenAI only's Resume import.
- Claude Code 2.1.285 runs Haiku 5.5 but reports it as an unrecognized model;
  update Claude Code with `claude update`.
- In a Resume proposal's Edit box, text is edited in its stored form:
  formatting shows as tags such as `<b>`, and a "<" that would start a tag
  shows as `<lt>`. Keep them as shown.
- Cover letter Polish treats text that looks like a formatting tag, such as
  `<b>`, as markup. In a body paragraph, Polish retries once and may then fail
  or drop that text. In a greeting or sign-off, the text becomes formatting
  when you accept the letter.
- Greenhouse job pages, iCIMS, and Dayforce still use slower parsers. Hostile
  markup served from those sites could still tie up the local server.
- PDF import was tested on synthetic resumes; accuracy on real-world layouts
  has not been measured.
- Gap statements in the Resume proposal come from the same model that writes
  the edits. In testing, a partly met requirement was occasionally marked
  Addressed.
- Backing up or restoring a workspace near the maximum through the desktop
  companion has not been verified yet.
- Extension 1.4.0's frame capture has not been hand-tested in an installed
  Chrome or Firefox extension.

## Included

- Native macOS downloads for Apple silicon and Intel, plus a native Windows x64
  installer and a checksum file covering every published artifact.

RoleFit's browser app, loopback server, paired extension, and workspace remain
on the user's device. AI input goes directly to the provider selected for that
stage only when the user runs the workflow; provider credentials and personal
workspace data are not part of the public release artifacts.
