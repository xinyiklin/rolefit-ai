# RoleFit AI 0.16.0: unsigned preview beta.1

<!-- Curated preview-note source. Publication occurs only after every native build, packaged smoke, installer lifecycle, checksum, and atomic-publication gate succeeds. -->

This unsigned public preview gives Claude Code its full instructions on
Windows, keeps text you type or paste that looks like a formatting tag as
plain text, and removes Antigravity CLI support. It includes browser extension
**1.4.0** and desktop bridge API **13**, both unchanged. RoleFit stays
local-first and browser-primary: there is no app account, hosted workspace,
cloud synchronization, or telemetry service.

Version 0.16.0 also retires GPT-5.5, stops two ways the application tracker
could lose data, and keeps a crafted job page from tying up the local server
during ordinary job import. It remains a preview rather than a stable release
because public installers are still unsigned, automatic updates are not
implemented, and portable formats may still change without migrations.

## Upgrading from an earlier preview

- **From 0.14.0 or 0.15.0:** 0.16.0 reads the same workspace, tracker,
  settings, and backups, and changes no file format, so upgrading needs no
  backup step.
- **Settings from any earlier version** are repaired when 0.16.0 loads them:
  - A stage set to Antigravity switches to that stage's default Claude Code
    or Codex model, and the companion drops Antigravity from its provider
    list. Your API keys and other providers are kept.
  - A Codex stage set to GPT-5.5 switches to Codex's default, GPT-6.1 Sol.
- **Rolling back to 0.14.0 or 0.15.0** is safe, with two differences:
  - To use Antigravity again, add it again in the companion and choose it
    again for each stage in Settings.
  - A "<" that 0.16.0 saved before tag-like text, as in a typed `<b>`, shows
    as `<lt>b>` in the older editor, its PDF, and the text sent to AI
    providers. Other "<" characters, as in `a < b`, are unchanged.
- **From 0.11.x through 0.13.0:** the RoleFit 0.14.0 preview's upgrade notes
  also apply. If you may return to 0.13.0 or earlier, create a
  `.rolefit-backup` before you use any of the 24 font families added in 0.14.0.
  Resume PDF import can choose one of those families, so a resume imported
  from such a PDF counts as using it.
- **From 0.10.0 or earlier:** the RoleFit 0.11.0 preview's upgrade notes also
  apply. After any launch of 0.11.0 or later, 0.10.0 and earlier refuse to
  save settings and refuse its backups. If you may need to roll back, create a
  `.rolefit-backup` in your current version before upgrading.
- The extension is unchanged from 0.12.0. If you are upgrading from 0.11.x or
  earlier, reload the unpacked extension once so it picks up extension 1.4.0.
  Firefox removes temporary add-ons when it quits, so load it again after a
  restart.
- Reload any RoleFit tab left open from the previous version.
- Quit the existing RoleFit application before installing this preview.
- On macOS, replace the existing `RoleFit AI.app` in Applications.
- On Windows, run the new installer over the existing installation. The
  installer retains RoleFit's internal upgrade and local-data identity.
- The installed companion continues to use the existing RoleFit workspace and
  provider configuration.
- Save important standalone cover letters as `.cover` files separately. The
  current `.rolefit-backup` allowlist does not include saved cover-letter
  variants.

## Before installing

- macOS Gatekeeper will identify the app as coming from an unidentified
  developer. The app has an ad-hoc integrity signature but is not notarized or
  signed with Apple Developer ID.
- Windows SmartScreen will warn that the publisher is unknown. The installer
  is not Authenticode-signed.
- Download only from the canonical RoleFit GitHub Release and compare the file
  against `SHA256SUMS.txt` before opening it.

## Changed

- **Antigravity CLI is no longer supported.** RoleFit works with four
  providers: Claude Code CLI, Codex CLI, OpenAI API, and Claude API.
- **GPT-5.5 is gone from the Codex model list.** It retired on October 14,
  2026.
- **Claude Code reads RoleFit's instructions from a private temporary file**
  that is removed after each run, on every platform. If a Claude Code run
  fails after you upgrade, update Claude Code with `claude update`.

## Fixed

- **Claude Code on Windows.** When Claude Code was installed through npm,
  Windows passed it only the first line of RoleFit's instructions and dropped
  the chosen model and reasoning effort, so runs used Claude Code's default
  model without RoleFit's rules against inventing facts. Longer instructions
  failed outright. Claude Code now receives the full instructions, model, and
  effort. If you used it this way, review AI edits you accepted in an earlier
  preview.
- **Tag-shaped text stays text.** Typing or pasting text such as `<b>`,
  `<size=12>`, or `<link=…>` in the Resume or Cover letter editor no longer
  turns it into formatting or makes it disappear. The text appears in the
  editor, the PDF, and Resume Polish as you wrote it. Cover letter Polish
  still has limits; see Known issues.
- **Tracker attachments no longer overwrite each other.** Two different file
  names that store under the same name, such as names in some non-Latin
  scripts or with different accents, used to replace the first file. The
  second now keeps its own copy, named with "-2", "-3", and so on.
  Re-uploading a file with the same name still replaces it.
- **Long notes are no longer clipped.** Notes and interview preparation used
  to lose everything past 8,000 characters when saved. Both fields now stop
  at 8,000 characters and show a count.
- **A bullet or skills row taller than a page** continues on the next page
  instead of running off the sheet.
- **Uppercase section headings** keep the case of link addresses in them.
- **Automatic links** keep a closing bracket that belongs to the address, such
  as `en.wikipedia.org/wiki/Foo_(bar)`.
- **PDF links** with parentheses, backslashes, or non-ASCII characters now
  open the right address. An unmatched ")" in a link used to produce a PDF
  that some readers could not open.

## Security

- **A crafted job page no longer ties up RoleFit.** Importing one, up to the
  5 MB import limit, could keep the local server busy for minutes or longer.
  Job import now reads ordinary pages in linear time. Some job-board pages
  still use slower parsers; see Known issues.
- **Resume Polish can no longer hide a link in an edit.** An edit that tucked
  a link inside formatting tags passed the check that limits proposals to
  bold, italic, and underline. Such an edit is now rejected.
- **The local server checks the Host and Origin of every request** except the
  browser extension's own routes, which keep their own origin check. This now
  includes its app files, not only API requests. A server run from source also
  stops serving the workspace folder to other localhost pages; the installed
  companion never served it.

## Known issues

- In a Resume proposal's Edit box, text is edited in its stored form:
  formatting shows as tags such as `<b>`, and a "<" that would start a tag
  shows as `<lt>`. Keep them as shown. Typing a new tag there adds
  formatting; to type a literal "<" before a tag name, write `<lt>`.
- Cover letter Polish treats text that looks like a formatting tag, such as
  `<b>`, as markup. In a body paragraph, Polish retries once and may then fail
  or drop that text. In a greeting or sign-off, the text becomes formatting
  when you accept the letter.
- The instructions file was checked against Claude Code 2.1.300's argument
  handling and with simulated Windows launchers, but not yet in a live Claude
  Code run on any platform.
- Pages fetched from Greenhouse embeds, iCIMS, or Dayforce still use slower
  parsers. Hostile markup served from those sites could still tie up the
  local server.
- A name formatted with a custom font or size adds text such as `size_24` to
  the suggested file name and the PDF title.
- PDF import was tested on synthetic resumes; accuracy on real-world layouts
  and live provider interpretation have not been measured. Two layouts read
  imperfectly, with no text lost:
  - A dated sidebar whose headings look like its entries, beside a column
    without bullets, reads as one column.
  - Some values at a tab stop stay joined to the title with a Check.
- Gap statements in the Resume proposal come from the same model that writes
  the edits. In testing, a partly met requirement was occasionally marked
  Addressed.
- During Polish again, the earlier proposal stays in the rail and its edits
  can still be accepted or discarded. Accepting one changes the document, which
  stops the new Polish.
- Backing up or restoring a workspace near the maximum through the desktop
  companion has not been verified yet. Large backups use substantial memory
  while they are built.
- Outside Rippling, a posting link that redirects to a general careers page
  imports that page's text as the job; check the brief.
- A posting inside a frame from another origin is still missed when that frame
  is not a recognized job-board posting, or when the frames name more than one
  posting.
- Lever and Jobvite frames were tested only with offline fixtures, not against
  live postings.
- Extension 1.4.0's frame capture has not been hand-tested in an installed
  Chrome or Firefox extension.

## Included

- Native macOS downloads for Apple silicon and Intel, plus a native Windows x64
  installer and a checksum file covering every published artifact.

RoleFit's browser app, loopback server, paired extension, and workspace remain
on the user's device. AI input goes directly to the provider selected for that
stage only when the user runs the workflow; provider credentials and personal
workspace data are not part of the public release artifacts.
