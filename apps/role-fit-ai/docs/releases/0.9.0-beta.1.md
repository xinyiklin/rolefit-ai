# RoleFit AI 0.9.0: unsigned preview beta.1

<!-- Curated preview-note source. Publication occurs only after every native build, packaged smoke, installer lifecycle, checksum, and atomic-publication gate succeeds. -->

This unsigned public preview packages the RoleFit 0.9.0 desktop/browser
milestone. It includes browser extension **1.2.1** and desktop bridge API **13**
while keeping the product local-first and browser-primary: there is no app
account, hosted workspace, cloud synchronization, or telemetry service.

Version 0.9.0 replaces Materials with an Answers conversation for employer
questions, records several reasons when you skip a job, reorganizes Settings,
and makes Resume and Cover Letter Polish more restrained. It remains a preview
rather than a stable release because public installers are still unsigned,
automatic updates are not implemented, and portable formats may still change
without migrations.

## Upgrading from an earlier preview

- **Before upgrading, create a `.rolefit-backup` in 0.8.0** if you may need to
  roll back. Trackers and backups saved by 0.9.0 do not open in 0.8.0: Skipped
  records now store a list of reasons, and Answers can save Draft records that
  0.8.0 does not recognize. 0.8.0 refuses such a tracker or backup without
  changing it. Before going back, also use Settings > Reset, because 0.9.0
  stores new Automation preferences.
- Existing Skipped records keep their single reason. The retired "Pay,
  location, authorization, or other constraint" reason stays on records that
  have it but is no longer offered.
- Earlier versions could remove the application date and saved documents from
  an application later marked Skipped when you skipped the same posting again
  or saved its job updates. 0.9.0 keeps that history; records already affected
  are not repaired.
- **Materials is replaced by Answers.** Existing saved application answers stay
  with their applications.
- New stage defaults apply only where you have not chosen a model: Job
  analysis, Fit, and Final review use Claude Sonnet 5.5 (low); Resume and Cover
  Letter Polish use Codex GPT-6.1 Sol (medium); Answers uses Claude Opus 5.5
  (high). Saved choices stay selected.
- Reload any RoleFit tab left open from the previous version before editing.
- Quit the existing RoleFit application before installing this preview.
- On macOS, replace the existing `RoleFit AI.app` in Applications.
- On Windows, run the new installer over the existing installation. The
  installer retains RoleFit's internal upgrade and local-data identity.
- The installed companion continues to use the existing RoleFit workspace and
  provider configuration.
- The browser extension is unchanged (1.2.1); no reload is needed.
- Save important standalone cover letters as `.cover` files separately. The
  current `.rolefit-backup` allowlist does not include saved cover-letter
  variants.

## Before installing

- macOS Gatekeeper will identify the app as coming from an unidentified
  developer. The app has an ad-hoc integrity signature but is not notarized or
  signed with Apple Developer ID.
- Windows SmartScreen will warn that the publisher is unknown. The installer
  is not Authenticode-signed.
- Download only from the canonical RoleFit GitHub Release and compare the file
  against `SHA256SUMS.txt` before opening it.

## Included

- **Answers replaces Materials**: a conversation for each preparation over the
  exact employer question. It drafts from the selected resume, your Profile,
  the edited job brief, the captured posting, and any facts you declare. Only
  explicit hard limits (words, characters, sentences) gate Copy and Save; other
  checks stay advisory. Save keeps an immutable revision with the facts you
  declared, and the first Save creates a Draft in Applications (no submission
  date, outside submission counts) that Apply or Skip later promotes. Unsaved
  Answers work is protected when a new preparation or saved application would
  replace it.
- **Skip & save job records any number of reasons** from a grouped list
  (Eligibility, Logistics, Fit, Status, Personal) plus an optional note. The
  dialog suggests reasons from evidence already on your device: an earlier skip
  of the same posting, a link to an application you submitted, a Fit
  eligibility condition, on-site or travel wording in the posting, or a Limited
  verdict. Each suggestion shows why, and none of it calls an AI provider.
- **Settings has five pages** in two groups: You (Profile, Background) and AI
  (Guidance, Automation, Models). Background lists the open resume's entries
  and links a note to an entry by choosing it.
- **Prepare picks from** (Settings > Automation) chooses which saved resume and
  cover-letter variants Prepare may pick automatically; the others still open
  by hand.
- **Optional Resume Polish review** (Settings > Guidance, off by default) holds
  back low-impact or incorrect edits, shown collapsed with a reason and
  Restore.
- **Resume Polish is more restrained**: it keeps each bullet's tense, skips
  churn such as synonym swaps, keeps numbers with what they count, and sends
  deletions of narrowing claim words to review.
- **Cover Letter Polish warnings** fire on far fewer honest sentences, name
  what failed, and stop repeating once a corrected issue is accepted.
- **Fit**: Assess fit and Reassess fit always work once a posting is prepared,
  even with automatic Fit off, and warnings appear beside the match, gap, or
  eligibility finding they concern in Prepare, the Applications inspector, and
  Application Detail.
- **Prepare** keeps whole items across long brief lists instead of cutting text,
  reports Fit size limits before any request while Job analysis still runs, and
  names the actual Resume Polish blocker when no provider is ready.
- **URL import** selects the exact posting on more job boards (Ashby,
  schema.org JobPosting pages, Oracle, iCIMS, Dayforce, Workable, UKG), and a
  missing LinkedIn, Greenhouse, Ashby, or Jobvite job fails with paste or
  extension guidance instead of importing board text.
- **The editor** saves up to eight named spacing presets; an existing Custom
  preset carries over.
- **The desktop companion** shows its version in Settings instead of the
  sidebar.
- Native macOS downloads for Apple silicon and Intel, plus a native Windows x64
  installer and a checksum file covering every published artifact.

RoleFit's browser app, loopback server, paired extension, and workspace remain
on the user's device. AI input goes directly to the provider selected for that
stage only when the user runs the workflow; provider credentials and personal
workspace data are not part of the public release artifacts.
